> 本书是最受普通投资者欢迎与推崇的投资经典之一。彼得·林奇用浅显生动的语言，讲述了一套简单易懂的业余投资者选股方法。

## 关于作者

**彼得·林奇**（Peter Lynch），美国乃至全球首屈一指的投资专家。1977～1990年，他担任富达公司旗下麦哲伦基金的经理人，13年间该基金资产由2000万美元成长至140亿美元，年平均复利报酬率达29%。

## 关于本书

本书系统讲述了：

- **投资准备**：克服心理障碍，建立正确的投资观念
- **挑选大牛股**：普通投资者如何利用自身优势找到10倍股
- **长期投资**：构建投资组合，选择买卖时机

林奇用自己成功的选股经历和丰富的实例，证明了业余投资者只要动用 3% 的智力，选择稳健的投资策略，就能获得更好的投资回报。
